## はじめに
自然言語処理（NLP）で注目される技術の一つが「BERT」です。Googleが開発したこのモデルは、検索エンジンや文章理解タスクで高い性能を発揮します。BERTは、**Attention機構とTransformer構造**の発展によって実現され、「単語の意味理解」だけでなく「文脈の双方向理解」や「長文処理」までできます。

自然言語処理の手法・加味できることは、下図のように進化してきました。本記事では、特にRNN・LSTM以降の技術革新に焦点を当てながら、BERTの仕組みを解説していきます。

## 1. RNN（再帰ニューラルネットワーク）
BoWやWord2Vecでは、単語の並び順に関する情報を保持できません。これを補完する方法にRNNが挙げられます。RNNは、時系列を扱うのが得意なニューラルネットワークの１つです。**文章も単語が順に並んでいるという点で、時系列データとみなして**RNNで扱うことができます。

## 1. Attentionとは：どの単語に注目すべきかを学習する仕組み
■ 従来手法の課題（Seq2Seq）
従来のEncoder-Decoderモデル（Seq2Seq）は、文全体を1つの固定長ベクトルに圧縮して表現します。この方法は短文には有効ですが、文が長くなると重要な情報が埋もれてしまい、精度が落ちるという問題がありました。

■ Attentionの登場
Attentionは、出力する単語ごとに「どの入力単語に注目すべきか」を毎回計算し、適切に情報を抽出します。これにより、長文でも情報を適切に保持したまま処理できるようになります。

■ 主な構成要素
アテンション重み：注目度を数値化（代表的な手法：加法注意・内積注意）
コンテキストベクトル：アテンション重みを入力ベクトルにかけて得られる加重平均ベクトル
ソフトアラインメント：単語単位で滑らかに入力と出力を対応させる仕組み

## 2. Transformerとは：RNNの限界を克服するアーキテクチャ
■ RNNの課題
RNNでは、単語を一つずつ順番に処理する必要があるため、並列化が難しく、学習に時間がかかります。さらに、長文では過去の情報が薄れてしまうという「長期依存」の問題もあります。

■ Transformerの特徴
Transformerは、Attentionの仕組みだけを使って文を処理します。全単語を一度に入力し、並列処理が可能な構造を持つため、高速かつ高精度な処理を実現できます。

■ 技術的特徴
自己注意（Self-Attention）によって、単語間の関係を学習
多頭注意（Multi-Head Attention）で多様な視点から情報を抽出
位置情報を保持するポジショナルエンコーディングの導入

## 3. BERTとは：事前学習済みの双方向エンコーダモデル
■ 概要
BERTは、Transformerのエンコーダ部分のみを用いた構造で、文の前後関係を同時に学習する双方向表現モデルです。従来の一方向モデルと比べて、文全体の意味をより深く理解できます。

■ BERTの学習プロセス（2段階学習）
事前学習（Pre-training）
マスク言語モデル（MLM）：文中の単語を一部隠して、正しい単語を予測させる
次文予測（NSP）：2文が連続するものかどうかを予測する
ファインチューニング（Fine-tuning）
事前学習済みモデルに出力層を追加して、分類・QA・感情分析など様々なタスクに対応
少ない学習データでも高い精度が出せるのが特徴

## 4. BERTでできること（活用例一覧）
| 活用領域    | タスク例                  |
| ------- | -------------------- |
| テキストの理解 | 文の意味理解、感情分析、カテゴリ分類など |
| 文と文の比較  | 類似性判定、含意判定（NLI）、重複検出 |
| 単語の意味解析 | 品詞、固有表現抽出、意味予測       |
| QA・文脈理解 | 文脈から情報を抽出            |


## おわりに
これらの技術背景を理解することで、BERTだけでなく、後継のLLMや生成AIの仕組みにもつながる知識となるでしょう。
