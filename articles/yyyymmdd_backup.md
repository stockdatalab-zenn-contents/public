## 1. 人物像
### 1-1.サマリ
高い知性と責任感を持ち、ADHD的な注意のムラやASD的な構造志向を同時に抱えている。つまり、**刺激への敏感さ（ADHD的覚醒）＋秩序を求める性質（ASD的補正） の二層構造を持ち**、行動的な混乱を防ぐために、几帳面・先回り・構造化を行う（秩序を作り出す）傾向がある。
| 項目    | 強み        | 弱み          |
| ----- | --------- | ----------- |
| 注意・集中 | 過集中力・正確性  | 優先順位づけが苦手   |
| 思考    | 論理的・分析的   | 柔軟な発想が苦手    |
| 感情    | 冷静・安定     | 自己否定・評価過敏   |
| 行動    | 計画的・前倒し   | 想定外に弱い      |
| 対人関係  | 誠実・信頼性が高い | 会話や即応が苦手    |
| 環境適応  | 自律的に働ける   | 刺激に敏感・疲れやすい |

### 1-2.基本情報
1995年生まれの女性。知能は高く、やや完璧主義。
ADHD傾向が優位、ASD傾向も併せ持つ（いずれも臨床的な障害レベルではない）。

### 1-3.対人・コミュニケーション
- 言葉がうまく出ず、焦るとパニックになり余計に言葉が出ない。
- 自分の考えを言語化することに強い抵抗があり、会話が苦手。
- 周囲を巻き込む力はあまり強くない。
- 相手の話を途中で遮ってしまうことがある。
- ただし、忘れ物や遅刻などの「社会的ルールの遵守」は高い水準でできている。

### 1-4.こだわり・興味
- 自分の生活に直接役立つこと（例：株式投資）への関心が非常に強く、深く探求できる。
- 興味のない分野には関心が持てない。
- 想定外の変更や急な予定に強いストレスを感じる。
- 一方で、単調な環境が続くと刺激を求める。

### 1-5.感覚・認知特性
- 光や音などの刺激に敏感。
- 全体よりも細部への注意が強い（分析的傾向）。

### 1-6.感情・ストレス反応
- 感情表現は控えめで、感情の起伏は小さい。
- 他者評価や失敗に敏感で、自己否定的になりやすい。
- 「嫌なことを避けるために努力する」という合理的な回避行動ができる。
- 締め切りのある仕事は前倒しで進める傾向がある（自己管理意識は高い）。

### 1-7.注意・集中・行動
- マルチタスクが苦手で、一つのことに集中しやすい。
- 集中力の波が大きいが、知的好奇心が高く学習への抵抗がない。
- 好きなことへの没頭力が強い。
- ケアレスミスは少なく、細部まで正確に仕上げようとする。
- 頭の中が常にフル稼働しており、リラックスが難しい。

### 1-8.仕事・生活スタイル
- 対人関係が少ない職種で高いパフォーマンスを発揮する。
- スケジュールやタスクの見積もりが苦手（優先順位づけも課題）。
- ただし、整理整頓は得意。
- 厳格なルールや上下関係より、柔軟で自律的な環境のほうが成果を出しやすい。
- 発想力・創造性よりも、分析・実行・管理の精度の高さで貢献するタイプ。

## 2. 強み
### 2-1. 高い知能と分析力
**知識や分析を積み上げるタイプの仕事（リサーチ、データ解析、品質管理など）で大きな成果を出しやすい**。
- 情報を構造的に整理し、正確さを重視して思考できる。
- 興味のある分野に対しては非常に深く探求し、理解を積み重ねられる。
- 感情に流されにくく、論理的に判断する力がある。

### 2-2. 責任感・誠実さ・完遂力
**細部の正確さが求められる業務（品質保証・会計・文書管理など）や、信頼を積み重ねる仕事で強みが発揮される**。
- 締め切りや約束を守る意識が強く、早めに行動する。
- ケアレスミスが少なく、丁寧で精度の高い仕事を好む。
- 「嫌なことを避けるために努力できる」ため、目標達成意識が安定している。

### 2-3. 集中力と持続力の高さ
**専門分野の深化型キャリア（研究、専門技術職、分析職など）で成果を出しやすい**。
- 興味のあるテーマでは強い集中力を長時間維持できる（“過集中”タイプ）。
- 新しい概念や情報の吸収力が高く、学習を負担に感じない。
- 長期的な目標を自分なりに設定し、淡々と努力を続けられる。

### 2-4. 感受性の高さと洞察力
**細やかな観察・改善が求められる職種（教育、心理・医療・サポート職など）に適性**。
- 光や音などに敏感で、細部や違和感を見抜く感覚が鋭い。
- 他人の言葉や表情から「本当の意味」を読み取ろうとする努力ができる。
- 感情表現は控えめだが、観察眼に優れるため、人の機微に気づける。

### 2-5. 自律性と自己管理力
**フリーランスや在宅勤務など、自分のペースで働ける環境に適している**。
- 遅刻や忘れ物をしない、整理整頓が得意。
- 混乱を避けるために、秩序や手順を自ら作る力がある。
- 厳しすぎる環境よりも、自分でルールを作って進められる環境でパフォーマンスが上がる。

## 3. 弱み
### 3-1. スケジュール管理と優先順位づけの苦手さ
- 複数のタスクを並行処理すると混乱しやすい。
- 細部にこだわりすぎて全体の進行が遅れることもある。
- やるべきことが多すぎると思考がフリーズしやすい。

### 3-2. 想定外の事態への弱さ
- 急な変更や曖昧な状況に強いストレスを感じる。
- 完璧主義的に「想定通りに進まない＝失敗」と捉えがち。

### 3-3. 対人コミュニケーションの負担感
- 自分の考えを言語化することに時間がかかり、会話がストレス。
- パニックになると余計に言葉が出にくい。
- 感情表現が控えめなため、誤解されることもある。

### 3-4. 感覚過敏と過集中による疲労
- 光・音・他人の存在などに敏感で、環境からの刺激で消耗しやすい。
- 集中しすぎて休憩を忘れ、後から一気に疲れる。

### 3-5. その他
- 失敗や他人の評価に過敏で、「自分はまだ足りない」と思いやすい。
- 真面目で努力家な分、心身が限界に達するまで頑張ってしまう。

## 4. 強み最大化・弱みカバー・習慣化で生きづらさを低減する
### 4-1.サマリ
強みの「内向的集中力（深く・継続的に考える力）」と「正確さ」を最大限に活かすには、**得意を自然に発揮できる環境を設計**し、**不得意を構造化で補う**ことが効果的です。

ADHD優位・ASD傾向があり知的水準が高い人は、努力である程度カバーできる分、無自覚に疲労を溜め込みやすい点みに注意が必要です。そのため、混乱を防ぐための秩序と、完璧主義を緩める余白を両立させるために、**型を決めて中身を自由に入れ替える環境設計**が理想です。

**強みの概要**
| 領域      | 強み                    |
| ------- | ------------------------ |
| 知的特性    | 高い分析力・論理的思考・集中力・学習意欲     |
| 行動特性    | 締め切り遵守・計画的・誠実・ケアレスミスが少ない |
| 感覚特性    | 細部への感度が高く、違和感に気づける      |
| 感情特性    | 感情の波が小さく、冷静に判断できる        |
| モチベーション | 「生活に還元できること」への探求心が強い      |
| 働き方      | 一人で深く考える仕事に向く・自律的環境で力を発揮 |

**弱みの概要**

| ------------------ | ------------------------------------------------------------------ | --------------------------------------------------- |

### 4-2.戦略１：【環境設計】「静かで整った構造」を味方にする
集中力を保つために「刺激を減らす」のではなく、**“安心刺激”を増やす環境づくり**を意識します。「集中するため」ではなく「集中しすぎて疲れないため」に整えるのがポイントです。
| 項目     | 推奨設定                      | 理由                        |
| ------ | ------------------------- | ------------------------- |
| 作業環境   | 静かな部屋／ノイズキャンセリング／シンプルな机周り | ADHD的注意散漫を防ぎ、ASD的秩序欲求を満たす |
| 照明     | 暖色・間接照明・一定の明るさ            | 光刺激を安定化                   |
| デジタル環境 | 1画面作業＋通知OFF＋固定アプリのみ       | 情報の氾濫を抑える         |
| 思考時間   | 朝の静かな時間を主軸に設定             | 思考・分析系タスクに最適              |

| 項目   | 習慣例              | 狙い            |
| ---- | ---------------- | ------------- |
| 睡眠   | 毎日同じ時間に寝起きする     | ADHDの覚醒リズム安定  |
| 食事   | 糖質・カフェインの摂りすぎに注意 | 集中ムラの抑制       |
| 運動   | 毎日15〜20分の軽い有酸素運動 | 注意力・ストレス耐性の向上 |
| デジタル | SNSや通知の使用時間を制限   | 過刺激の抑制        |
| 趣味   | 目的のない没頭を週1回    | 完璧主義の緩和       |

- 定位置ルールで整理整頓を習慣化
整理の得意さを維持しつつ、ADHD的な注意の漏れを予防する。
よく使う物の位置を固定し、使ったら戻すことを徹底する



### 4-3.戦略２：【タスク設計】「構造化」と「見える化」で脳を助ける
強みの論理的思考力・正確性を引き出しつつ、ADHD的混乱を防ぐ。細かく「決める」より、**枠だけ決めて中身を入れ替える**運用が合う。タスクをあまりに細かく分解しすぎると、情報過多で行動・思考が停止してしまうことに注意する。
| 方法             | 内容                         | 効果                  |
| -------------- | -------------------------- | ------------------- |
| 3層構造化   | ゴール・中間成果・次の行動<br>今すぐ・今週中・後で<br>などに分類する          | 思考の迷子を防ぐ            |
| 視覚タスクボード   | TrelloやNotionで「進行中・完了」を可視化 | 達成感が得やすく継続動機に       |
| テンプレート活用   | 毎回の手順を固定化（例：資料作成手順書）       | ASD的安定感＋ADHD的スピードUP |
| 「3タスク/日」制限 | 1日に決めるタスクを3つに限定            | 完璧主義＋多動傾向の過負荷を防止    |
| マルチタスク禁止 | タブやアプリは最小限に開く<br>「今やっていること」をメモに書いておく（再集中しやすくなる）            | ADHDの注意の拡散を抑え、ASD的な順序性を活かす    |

また、完璧主義でエネルギーを使いすぎないために、タスクごとに「理想の8割」を上限と決める。ADHDの過集中とASDの完璧主義の両方を防ぐ。

:::details 参考：なぜ細かくしすぎると思考が止まりやすいのか
「完璧に分けたいASD脳」と「次々に思いつくADHD脳」が同時に働き、フリーズする。
| 特性           | 背景                       | 結果                       |
| ----------     | ------------------------   | -------------------------- |
| ASD傾向        | 完璧に整理したい<br>全体構造を把握してから動きたい | 細部まで考えすぎて動けなくなる（思考優先）      |
| ADHD傾向       | 興味の移り変わりが早く、情報を一気に展開する       | 細分化が枝分かれして収拾がつかなくなる        |
| 知的水準の高さ | 抽象思考と具体思考を同時に動かせる                 | 「どこまで分けるのが最適か」を考えすぎて決められない |
:::




### 4-4.戦略３：【時間設計】「集中×回復のリズム」を固定化する
#### ■日次単位
##### 午前（トレード後～昼休憩前）
脳が冴えていない時間帯。静かな音楽・自然光・温かい飲み物などで、脳を低起動状態にする。ADHD的集中の低下タイムでも実行できるルーチン作業・メール処理などをする。
##### 日中（昼休憩後～退勤前）
脳が冴えている時間帯。強みの「論理＋集中力」を最大化する。途中で意識的休憩を挟み、過集中による疲労崩壊を防ぎ、日中パフォーマンスを持続させる。
##### 夜（夜ご飯・お風呂～就寝前）
- **22:30前**
自由時間。
- **22:30以降**
脳への新しい刺激をシャットアウトする。感覚を落ち着かせる。身体を鎮める（体の緊張をほぐす）。
  - 思考を落ち着かせる。
就寝前に3項目を書く。ASD的な反省過多を前向きにし、ADHD的な勢いの一日に区切りをつける。ストレスと自己評価を整えるため、不快や不安は1行メモ＋タグで可視化し、自己否定を防ぎ再発を防ぐ。（例：「急な予定変更があった」→ #予測不能、「人に否定された」→ #評価過敏）
：今日うまくできたこと・感情が動いた瞬間・明日やめたいこと・続けたいこと
  - 五感を落ち着かせる
：照明を暖色に変える・ハーブティーを飲む・静かな音楽をかける or 音を止める・ストレッチをする・呼吸だけに意識を置く

#### ■週次単位
| 曜日   | 集中テーマ                               | 回復テーマ |
| ---    | --------                                 | -----      |
| 月木   | 予定やタスクの見直し・<br>調査・作業準備 | 早め就寝   |
| 火水金 | 作業                                     | -          |
| 土日祝 | 整理・学び                               | 感覚オフ   |

| 項目   | 習慣例              | 狙い            |
| ---- | ---------------- | ------------- |
| 睡眠   | 毎日同じ時間に寝起きする     | ADHDの覚醒リズム安定  |
| 食事   | 糖質・カフェインの摂りすぎに注意 | 集中ムラの抑制       |
| 運動   | 毎日15〜20分の軽い有酸素運動 | 注意力・ストレス耐性の向上 |
| デジタル | SNSや通知の使用時間を制限   | 過刺激の抑制        |
| 趣味   | 「目的のない没頭」を週1回    | 完璧主義の緩和       |

#### ■人との距離感を自分で選ぶ
コミュニケーション疲労を減らし、思考の余白を守る。
集団より1対1、リアルよりチャットやメール中心を選ぶ
定期的に「会話しない日」を設けて回復時間を確保

| 体調 | 五感のオフ時間を毎晩つくる | 感覚過敏による脳疲労を防ぐ         |

#### 強みを活かせる環境・働き方
| 環境タイプ                | 向いている理由             |
| -------------------- | ------------------- |
| 明確なゴールがある個人タスク型  | 自律的に正確に進められる        |
| リモート・ハイブリッドワーク   | 感覚刺激の少ない環境を自分で調整できる |
| 分析・リサーチ・技術・管理系職種 | 集中・正確性・論理力が活かせる     |

#### 強みを潰さないための注意点
| 落とし穴        | どう避けるか                  |
| ----------- | ----------------------- |
| 完璧主義で動けなくなる | 「80点で提出」ルールを自分に課す       |
| 集中しすぎて休めない  | タイマーで強制休憩を入れる           |
| 環境に引きずられる   | 仕事・生活スペースを明確に分ける        |
| 他人の評価に過敏    | 評価を“データ”として捉える（感情で受けない） |

#### 疲れやすい状況とその予防策
:::details 認知的疲労（思考・判断過多）
- **疲れやすい状況**
  - 情報量が多い環境（複数の案件・画面・メールなど）
  - 優先順位をつけるタスク（意思決定が多い）
  - スケジュール調整・リスケジュールが頻発する
  - 想定外の変更に対応しようと頭の中で何度も再シミュレーションしている
- **予防策**
考える時間を「1日の中で意図的に制限する」。“考えすぎて疲れる”を“決めすぎて疲れる”にしない。

| 対応策                | 具体例                           |
| ------------------ | ----------------------------- |
| **決定回数を減らす**       | 「朝の服・昼食・作業順」は固定化する（意思決定を自動化）  |
| **思考の“出しっぱなし”を防ぐ** | 頭に浮かんだことを即メモ。後で整理。            |
| **1日1テーマ制**        | 同じ日に“分析系”と“調整系”の仕事を混ぜない。      |
| **集中時間を区切る**       | 50分集中＋10分リセット（ポモドーロ法）で過集中を防ぐ。 |
:::
:::details 感覚的疲労（光・音・人の気配による刺激過多）
- **疲れやすい状況**
  - オフィスやカフェなどで周囲の音・人・光が多い
  - モニターの光が強すぎる
  - 通勤・会議・雑談などで多人数に囲まれる
- **予防策**
“刺激を減らす”ではなく“安心刺激を増やす”という意識を持つと続きやすい。

| 対応策                | 具体例                                    |
| ------------------ | -------------------------------------- |
| 視覚刺激を減らす       | モニターの明るさを下げ、夜は暖色系照明に切り替える。             |
| 聴覚刺激を遮断        | ノイズキャンセリング・耳栓を常備。                      |
| 嗅覚・触覚の安心刺激を与える | 香り・素材・温度で「落ち着く感覚」を常備（例：好きな香りのハンドクリーム）。 |
| 外出後のリセット時間を確保  | 帰宅後すぐに照明を落として5分静止する。                   |
:::
:::details 時間・タスク管理による疲労
- **疲れやすい状況**
  - 予定が立て込んでいる日
  - 想定外の変更でスケジュールが崩れた
  - 優先順位が分からず、頭の中で何度も並べ替えている
  - 締め切りが複数重なる
- **予防策**
タスク管理の目的は「予定通りに進める」ではなく、「脳を混乱させない」こと。

| 対応策                    | 具体例                      |
| ---------------------- | ------------------------ |
| 朝5分で「今日の3タスク」だけ決める | 「今すぐ」「今日中」「後で」に分類。       |
| 余白時間を強制的に入れる       | 各予定の間に30分のバッファを設定。       |
| “1日1遅延は想定内”と決めておく  | 完璧に守れないことを前提に計画を立てる。     |
| 「完了」より「区切り」を意識**     | “完成”ではなく“進捗を止めた地点”で評価する。 |
:::
:::details 対人・コミュニケーション疲労
- **疲れやすい状況**
  - 話しながら考えることを求められる場面（会議・雑談など）
  - 相手の感情や意図を読む必要がある人間関係
  - 短時間に複数の会話・相談が続く
  - 断る・頼むなど、曖昧な言葉選びが必要なやり取り
- **予防策**
会話は“集中作業”に近い。話した分だけ、回復時間を必ずセットで確保することが重要。

| 対応策                | 具体例                         |
| ------------------ | --------------------------- |
| 話す前に書く       | 会話前にメモで考えを整理。チャットで伝える形式を選ぶ。 |
| 返事を保留する癖をつける | 即答せず、「少し考えます」で時間を確保。        |
| 会話数を制限         | 「1日にリアルな対話は2件まで」などの上限設定。    |
| 会話後のリセット儀式     | 飲み物・深呼吸・音楽などで脳の緊張を解く。       |
:::
:::details 感情・評価による精神的疲労
- **疲れやすい状況**
  - 他人の反応や評価を気にする
  - 小さな失敗を繰り返し思い出す
  - 自分の感情を我慢し続ける
  - 「本当は嫌なのに頑張る」状態が続く
- **予防策**
感情の整理を“反省”ではなく“情報処理”として行う。これにより、心の消耗を大幅に減らせます。

| 対応策                  | 具体例                             |
| -------------------- | ------------------------------- |
| **1日3行日記           | 「できたこと」「感じたこと」「次やめること」を書く。      |
| **“嫌”を数値化          | 嫌な予定・人・環境に0〜10の点数をつける。7以上は回避対象。 |
| **“頑張らない日を設ける     | 週1日は「生産しない日」としてスケジュール化。         |
| **他人の評価を“データ”として扱う | 感情的に受けず、「傾向を見る」意識に切り替える。        |

:::
:::details 肉体的疲労（脳と体のリズム差）
- **疲れやすい状況**
  - 集中しすぎて休憩を忘れる
  - 睡眠の質が悪い
  - 体を動かさずに1日が終わる
  - カフェイン・糖質過多で脳が過覚醒
- **予防策**
脳と体の“使用リズム”を合わせると、疲れが溜まりにくくなります。

| 対応策                   | 具体例                      |
| --------------------- | ------------------------ |
| **「1時間に1回、椅子から立つ」**   | 立ち上がって3分歩く・ストレッチ。        |
| **就寝1時間前は“脳をオフライン化”** | スマホ断ち・照明暗化・音量OFF。        |
| **カフェインカット時間を設定**     | 午後14時以降はノンカフェイン飲料に切り替える。 |
| **朝の“軽いリズム運動”**       | 散歩・スクワットなどで交感神経を整える。     |

:::

### 4-6.習慣で弱みを補う
① 外的刺激をコントロールし、② タスクを構造化して、③ 深く掘れる時間を確保することが重要。明確なルールやゴールがある環境・自分のペースで進められる作業・一人で深く考える仕事などで、知性と集中力を最大限に発揮できる。目的が「負荷の低減」であることを踏まえた上で、負荷の低減に最も良い影響（波及効果など）が出得るものや、どれだけ負担なく始められるかものから習慣化する。継続が必要なものはハードルを下げて早めにスタートさせる。

| 弱み          | 習慣での補い方          | 補う方向性             |
| ----------- | ---------------- | ----------------- |
| スケジュール管理が苦手 | 朝の3タスクルール        | 選択肢を減らす         |
| 想定外に弱い           | 代替案A/Bを常に持つ      | 柔軟性をシミュレーションで確保 |
| 会話が苦手             | 文章・チャットでの発信に切り替え | 自分のペースで言語化      |
| 感覚過敏               | 五感リセットルーティン           | 刺激の量をコントロール     |
| 自己評価が厳しい       | 3行日記・8割ルール       | 完璧主義を構造的に緩める    |

## 5. 主な困りごとの負担を軽減する
### 5-1.主な困りごと１：タスクの細分化
#### 苦手な原因
ASD傾向（全体を整えたい）とADHD傾向（すぐ行動したい）が同時に存在するため、全体像を描こうとして行動が止まる（ASD側の影響）・行動を始めても途中で混乱する（ADHD側の影響）という「二重のブレーキ」がかかる。つまり、「構造化しすぎて動けない」と「動きすぎて整理できない」が交互に起きる。

| 観点     | 内容                                      | 背景       |
| -------  | --------------------------------------- | --------------- |
| 認知構造 | 全体像を先に把握しようとするため、<br>分ける前に「完璧な地図」を描こうとする    | 完璧主義＋ASD的構造志向   |
| 注意制御 | ADHD的な注意のムラで、どこをどこまで<br>分ければいいかの線引きが曖昧になる | 集中力の波が大きい       |
| 感情反応 | 「細分化＝めんどくさい・混乱する」と感じ、<br>途中で思考がストップ         | 変化や曖昧さに対する抵抗感   |
| 時間感覚 | 時間の見積もりが苦手なため、<br>細かく分けてもスケジュールが破綻する不安      | ADHD的時間感覚の弱さ    |
| 言語化   | 頭の中のイメージを言葉に<br>落とすのに時間がかかる                 | 考えを言葉にすることが負担 |
| 情報処理 | 一度に多くの情報を抱え込み、<br>階層構造を整理できなくなる             | 全体把握が過剰に細部志向になる |
| 感情面   | 「できない自分」に対する自責・焦りが生じ、<br>行動意欲が下がる           | 自己評価が厳しい        |

#### 対策
細分化は、「分けること」や「全部を見通す作業」ではなく、「**手順を見える化して脳を軽くすること**」「**始めるための手順書**」と捉える。

:::details 手順１：XXXXX
- 3層ルールで分けすぎを防ぐ
完璧主義で細分化しすぎると、逆に混乱します。3階層までしか作らないルールを設定します。
- 手順をテンプレート化
| 質問            | 記入例         |
| ------------- | ----------- |
| ゴールは何？        | プレゼン資料を提出する |
| ゴールに必要な中間成果は？ | 構成案・下書き・最終版 |
| 最初の1ステップは？    | テンプレートを開く   |
| 所要時間の見積もりは？   | 30分         |
| 締め切り前に余裕を取る日  | 提出2日前       |

:::
:::details 手順２：動詞＋目的語で書く
抽象的なToDo（例：「資料作成」）ではなく、**次にやる行動・最初の１歩**として2分以内に行動を始められるくらいの粒度にして書く。また、頭の中で整理せずに、順番を決めずに書き出して（構造化は後回し）思考を外に出して可視化すると、整理力が上がる。
| Before | After（行動ベース）     |
| ------ | ---------------- |
| 資料作成   | テンプレートを開く        |
| 投資リサーチ | 銘柄リストをコピーしてメモに貼る |
| 片づけ    | 机の右半分の書類を分類する    |
:::
:::details 手順３：時間で区切る（完璧主義対策）
「完成させる」ではなく、「20分だけやる」という形でタスク化する。時間を制限すると、「途中で終えてもOK」という「許可」が出せます。また、考えすぎの無限ループを防ぎます。
| Before | After         |
| ------ | ------------- |
| データ整理  | データを20分だけ確認する |
| 記事執筆   | 1段落だけ書く       |
:::
:::details 手順４：タスクの「入口」と「出口」を定義する
各タスクごとに、始める条件と終える条件を明確にする。これにより「いつ始めたらいいかわからない」「どこで終わりか分からない」という迷いを防ぐ。
| タスク     | 入口           | 出口            |
| ------- | ------------ | ------------- |
| 株式情報の整理 | 朝10時にニュースを開く | Excelに3行メモを書く |
| 資料作成    | Wordを開く      | 下書きを保存する      |
:::



### 5-2.主な困りごと２：スケジュール管理
#### 苦手な原因
ADHD的には「順序づけ」が苦手で、ASD的には「想定外の変更」や「順序の乱れ」に強いストレスを感じるから。

#### 対策
リスケジュールは、ズレた自分を責めずシステムで吸収すること。
月次予定は適当に立てて、マイルストーンは気にしておく

:::details 手順１：ブロック式のスケジュールにする
時間単位ではなく、時間帯単位で予定を組むと負荷が下がる。各ブロックに「やること1つ＋余白」を必ず設定することで、 ADHDの時間見積もり誤差を吸収する。
| ブロック       | 例       | 目的               |
| ---------- | ------- | ---------------- |
| 朝（9–12時）   | 集中タスク1件 | 頭が冴えている時間に思考系を配置 |
| 昼（13–15時）  | 軽作業・返信  | 集中が切れやすい時間       |
| 夕方（16–18時） | 振り返り・整理 | 締め切り前の確認・軽作業     |

:::
:::details 手順２：見える化ツールを使用する
言語処理が苦手な方には、視覚的ツールが有効です。「1タスク＝1カード」ルールを守ると混乱しない。
- アナログ：付箋・ホワイトボード（タスクを並べ替えやすい）
- デジタル：Trello、Notion、Googleカレンダー（ドラッグでリスケジュールがしやすい）
:::
:::details 手順３：リスケジュールの習慣化
##### 捉え方を工夫する
ADHD傾向の方は、予定がずれると自責に陥りやすく、ASD傾向の方は変更そのものにストレスを感じる。「遅れた＝失敗」ではなく,、「**変更は修正ではなく学習**」「**情報更新**」と考える。
| 状況           | 自責型の反応    | 学習型の置き換え            |
| -------        | ----------      | ------------------- |
| タスクが遅れた | またできなかった| この時間では足りなかったと分かった |
| 急な予定変更   | ペースが崩れた  | 次は余白を30分増やそう  |

##### リスケ時間をあらかじめ組み込む
毎日夕方や就寝前に10分だけ「見直しタイム」を固定。
- 今日できたことに〇をつける
- 残ったタスクを翌日のブロックにドラッグ
- 余白を埋めすぎていないか確認

##### 遅延の原因をタグで可視化する
タスクが遅れたら、理由を短くタグ化して記録する。（例：#集中切れ #疲労 #予定変更 #時間見積もり誤差）パターンを3〜5回見ると、「自分の苦手パターン」が見えてくる。それを次回の見積もりに反映させると精度が上がります。

##### 感情と完璧主義のマネジメント
- リスケした自分を責めないメモ
予定がズレたときに「どうしてズレたか」を事実ベースで書く。 感情的な自己否定を防ぎ、認知を整える。
- 優先順位の再評価を定期的にする
1週間に1回、「何が本当に大事か」を見直す時間を設ける。 ASD的な“ルール固定”をやわらげ、ADHD的な“興味変動”に柔軟に対応できる。

##### サポート環境の構築
| 課題           | サポート例                          |
| ------------ | ------------------------------ |
| リスケが後回しになる   | タスクツールに「今日の振り返り10分」リマインダー      |
| 見積もりが甘い      | 過去の実績をメモして平均所要時間を把握            |
| パニック時に思考が止まる | 「緊急時マニュアル」（呼吸・離席・再着手の手順）を手元に置く |
| 集中しすぎて休めない   | タイマー or 音声アラームで強制休憩            |
:::



### 5-3.主な困りごと３：コミュニケーション（会議）
人との物理的な距離が近い状況において、他者の反応や表情から色々察して焦って早口になり上手く話せない。

#### 苦手な原因
ASD的な感覚過敏＋ADHD的な緊張反応 が重なって起きている現象。

| 原因タイプ    | 背景                              | 結果                    |
| ------------  | ------------------------------- | -------------------------- |
| 感覚過敏（ASD） | 相手の表情・視線・仕草・呼吸・雰囲気などを一度に処理してしまう | 読み取りすぎて脳が過負荷になり、逃避反応が起きる |
| 緊張覚醒（ADHD）| 早く終わらせようと体が戦闘モードになる             | 呼吸が浅くなり、早口になる         |
| 認知反応      | 相手にどう思われてるかを即座に分析し始める           | 自動思考が暴走し、話の主導権を失う          |
| 表出制御      | 焦りを抑えようと意識しすぎて、逆に挙動が不自然になる | ASD的な制御しようとする癖            |



#### 対策
焦りを抑えるよりも、**焦りが起きにくい身体と環境**を作ることがポイント。「察する力」は本来、非常に高い共感知性。それを「全部感じ取ろうとしない訓練」をするだけで、相手に飲み込まれずに自分のリズムで話せる人になれる。

:::details 事前準備
- **物理的距離を自分で選べる形にする**
ASD傾向では、相手の動きを視界に入れない工夫が非常に有効。
  - できる限り 少し距離の取れる場所を選ぶ（1.5〜2m）
  - 丸テーブルよりも 斜め向かい／L字の配置 が落ち着きやすい。
  - 立って話すより 座って報告 のほうが身体反応が安定する。

- **視覚刺激を減らす**
ASD的過剰共感を防ぐには、視覚負荷をコントロールすることがポイント。
  - 目線を「相手の顔の輪郭」や「首元・資料」に固定してもOK（目を見続けなくて良い）
  - プレゼン時は 資料・スライド・紙を“視線の逃げ場”にする

- **体の緊張を減らす呼吸を事前に練習する**
焦りや早口は自律神経の反射。つまり、意識的に呼吸と身体を落ち着かせる習慣を持つと反射を和らげられる。
「3秒吸う→2秒止める→5秒吐く」と吐く時間を長くすることで、副交感神経が優位になる。

- **「話す内容」を“視覚構造”で整理しておく**
マチさんは言語よりも構造で考えるタイプなので、話す順序を箇条書きやマインドマップで事前に整理し、「構造が見えている状態」にすると、焦っても順番を見失わない。

:::
:::details 当日
① 「話す前の3秒」ルール
話し始める前に、3秒だけ沈黙してから始める。（相手の目を見ず、手元を見ながらでOK）
“3秒の静止”が、脳に「安全だ」と教える信号になる。一度リズムを整えると、焦りスイッチが入りにくい。

② 話すテンポを資料に合わせる
話を自分のテンポではなく、“ページやスライドのテンポ”に同期させる。 ADHD的な“早口の暴走”を、外部リズムで制御する。
- 1枚につき2〜3文話すと決めておく
- 1項目ごとに呼吸を1回を意識する

③ 視線のアンカーを作る
緊張する相手の表情を避けたいとき、固定できる対象（資料など）を決めておく。そこに目線を置いて話すことで、情報過剰処理を防ぐ。
相手の反応は視界の端）で感じる程度で十分。

④ 聞かせるのではなく、伝達作業と考える
うまく見せようとすると、相手の表情解析モードが起動する。代わりに「情報を渡す作業」と捉えると冷静になる。

⑤ 終わり方を自分で決めておく
焦ると締め方が乱れやすいので、決まり文句を事前に準備しておくと安心できる。ASD的な秩序感を満たし、安心して話を締められる。
- 「以上が現状のご報告です。ご質問あればお願いします。」
- 「次のステップとしては、こちらの3点です。」

:::
:::details 長期的なトレーニング
| トレーニング               | 内容                   | 狙い                    |
| -----------------          | -------------------- | --------------------- |
| 音読練習（1日5分）         | ゆっくり・区切って・抑揚をつけて読む   | 口の動きと呼吸リズムの連動を学ぶ  |
| ミラー・セルフプレゼン練習 | 鏡を見て表情と声を確認（無理に笑顔不要） | 自分の声と表情を客観化し、焦りを減らす |
| 安全な人とのリハーサル     | 信頼できる人（家族・同僚）に向けて練習  | 人が近い状態への順応練習        |
| 短時間報告の反復           | 30秒・1分・3分で同じ内容を話す練習  | 焦らず要点をまとめる訓練          |
:::






### 5-4.主な困りごと４：コミュニケーション（相談）
適切なタイミングで相談ができない
※タスクに関しては、**手段が複数ある場面で最適解を選ぶ時**に相談することができている。

#### 原因
「早めに相談できない」「予定通りに実行できない」「切り上げの見極めができない」という３点は、実はすべて 同じ根本メカニズム（ASD＋ADHD的な自己モニタリングの難しさ） から生じている。自分の困りごとをリアルタイムに“把握・言語化”する負担が高すぎることによる。
| 背景         | 内容                   | マリさんの状態での表れ方                   |
| ---------- | -------------------- | ------------------------------ |
| ASD的傾向  | 言葉にする前に構造を整理しようとする | 「もう少し整理してから相談しよう」と思って遅れる       |
| ADHD的傾向  | 注意が今の作業に吸い込まれる     | 困っていると気づくのが遅れる／気づいた時には手遅れ気味    |
| 完璧主義的傾向 | 中途半端な状態で伝えることに抵抗   | 「まだ明確に説明できない」「言っても理解されないかも」と思う |
| 感情的要因   | 相談＝迷惑をかける、評価が下がると感じる | 安心して助けを求められない                  |


#### 対策
自己モニタリングを外部化し、判断を人ではなく仕組みに委ねることが有効。


:::details 手順１：相談のトリガーを外部化する（自動で気づく仕組み作り）
自分の感覚で「そろそろ困ってる」と気づくのは難しい。そのため、 外部化された**相談のサインを設定**する。完璧に整理できてから相談」ではなく、整理できなくなった瞬間が、相談すべきタイミングと考える。
| トリガー例                 | 相談のサインとして使う基準             | 対応行動                         |
| --------------------- | ------------------------- | ---------------------------- |
| 時間超過                | 想定より30分長引いたら「誰かに状況を言語化する」 | Slackやメモに「今ここで詰まっている」と書くだけ   |
| 同じ操作を3回繰り返した       | 詰まっている証拠                  | 「今の手順を共有・確認する」トリガーにする        |
| 集中が切れて他のタブを開いた     | 無意識の逃避反応                  | 「疲労サイン」→ 5分休憩＋“状況整理メモ”を書く    |
| 「次どうすればいい？」と頭の中で思った | 書き出す・相談準備サイン              | “まだ整理できていないけど…”の状態で話してOKと決める |

:::
:::details 手順２：相談を段階化してハードルを下げる
「相談＝会話・対話」と捉えているため心理的負荷が大きい。まずは**文章や記録ベース**から始めるのが有効。困りごとを言葉にする訓練から始める。
| 相談段階          | 内容                          | 負荷レベル |
| ------------- | --------------------------- | ----- |
| Lv1：自己メモ相談 | メモ帳に「困っていること／今考えていること」を書くだけ | 最低    |
| Lv2：チャット相談 | テキストで共有。「まだ整理途中ですが…」を前置きに   | 低     |
| Lv3：口頭相談   | 相手に直接伝える（口頭で補足・質問される段階）     | 中     |

:::
:::details 手順３：相談をスケジュールに組み込む
ADHD傾向では「必要になったら相談する」では間に合わない。定期的に相談の時間を固定する。
| 項目   | 内容                            |
| ---- | ----------------------------- |
| 形式   | 毎週◯曜日15分などの「定例チェックイン」         |
| 内容   | 「今週うまくいったこと」「詰まっていること」だけ話す    |
| 準備   | 当日までに1〜2行メモを残しておく（未整理でもOK）    |
| メリット | 定期枠があることで、“困ってから”ではなく“習慣で出せる” |

:::
